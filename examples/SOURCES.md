# Example images in `datasets/tiny_images.zip`

Three small public-domain photographs from the [NASA Image and Video Library](https://images.nasa.gov/). They are used only as a pipeline smoke test. None are commercial stock, celebrity portraits, or the upstream `dog.jpg` (whose license is unclear).

Each file in the zip is NASA's official **small** JPEG derivative of the listed NASA ID. NASA media is generally in the public domain in the United States (NASA media guidelines). Credit NASA (and the instrument teams named below) if you reuse them.
