Qwen-VL Batch Captioner

A Runpod Serverless worker that batch-captions images for LoRA / diffusion datasets with official Qwen3-VL-4B-Instruct and returns kohya-style sidecar .txt files plus captions.json. Optional short VQA.

GitHub Runpod Hub README

What you send / what you get

  • Send a dataset_url to a zip of images, or a single image_url.
  • Get a sidecar .txt next to each image (the format kohya / the image-lora trainer expect) and a captions.json manifest.
  • Default: caption, medium, English (“Describe this image.”); bfloat16; official 1280*32*32 pixel budget; RTX 4090 24 GB.

Not the same as

  • JoyCaption Batch Captioner — formal / descriptive / tag-style captions with JoyCaption Beta One.
  • Image LoRA trainer — that trains a LoRA; this only writes captions.
  • A general vLLM / OpenAI-compatible Qwen-VL chat server — not this listing.

Example job

{
  "input": {
    "dataset_url": "https://example.com/images.zip",
    "mode": "caption",
    "length": "medium",
    "language": "en"
  }
}
